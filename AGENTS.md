# Wyrm macOS — agent rules

Read ../CLAUDE.md and the workspace Desk first. Owner: OM Rajput.

- Current scope: Desktop engine, basic arena picker and playable test app.
- Never change protocol, challenge, join, socket ownership or game rules.
- SharedEngine is a hash-pinned transport snapshot of the live Android engine
  used by Desktop. Mac adaptations are generated by Scripts/prepare-engine.py;
  never edit the snapshot directly. Refresh the manifest with source changes.
- Build/push only when OM requests a build. No beta/stable publication without
  his agreement. CI artifacts are development test downloads.
- macOS 12+, both x86_64 and arm64. Native SDL main thread and direct presentation.
- No account UI yet: every engine setting is ephemeral in a per-session temp
  directory. When accounts arrive, use platform macos and existing shared keys.
- Keep exactly README.md, AGENTS.md, ARCHITECTURE.md plus license/privacy notices.
- Report source verification, Apple compilation and physical gameplay separately.
